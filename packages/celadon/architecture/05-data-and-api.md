# 05 · 数据与接口

- **版本**：v2.0（草案，待讨论）
- **最后修改**：2026-10-03 11:14:08
- **说明**：接口面 · 类型与落位 · 取数钩子 · 流式 · 禁止

## 1. 规则

- **接口面只有一套**：全部经 well-known 的 `openapi` 前缀（如 `/v1`）—— **本地引擎与远程服务端用同一套接口**，
  只是地址不同（见 `15-platform.md` §4.2 · §6.2）；**不为本地单开私有接口**。
- **不兼容旧接口**：不为旧服务端的路径 · 字段 · 鉴权写法做兜底；前端与服务端成对发布（同 `15` §3.1）。
- **传输与鉴权不在本层**：一律经 `platform/transport/`（见 `15` §4.4）；本层不出现 `fetch` · `Authorization` · cookie 读写。
- **类型手写**：接口类型写在 `app/src/data/`，**不从 `openapi` 生成**（服务端没有机器可读的文档）。
- **取数只有一条路**：组件与 feature 经**取数钩子**拿数据，不自己拼 URL、不自己建 WebSocket。
- **错误只有一个形状**：所有接口错误归一为同一形状，业务只判一种。
- **流式也经 `transport/`**：SSE 与 WebSocket 都用它的流式能力，不裸用浏览器原生对象。

## 2. 接口面

按服务端的分组切模块，一个域一个文件：

| 域 | 覆盖 |
| --- | --- |
| `user` | 资料 · 偏好 · 团队与成员 · 邀请 · 订阅与额度 |
| `setting` | 偏好 · API Key · MCP 服务器 |
| `agent` | 助手 · 看板 · 任务 |
| `kb` | 集合 · 文档 · 段落 · 检索与投票 |
| `file` | 上传 · 下载 · 存储 |
| `workspace` | 工作区 · 文件 · Git 配置 |
| `chat` | 会话与流式补全 |
| `llm` · `mcp` · `sandbox` · `trace` | 模型 · MCP · 沙箱 · 轨迹 |

- **模块只声明方法与类型**：基址 · 鉴权 · 错误归一都在 `transport/`，模块里看不到。
- **命名跟服务端口径**：路径段与字段名不改写，少一层翻译就少一处漂移。

## 3. 类型与落位（`app/src/data/`）

- **手写强类型**，形状约定：可空性照服务端实际（`string | null`）· 可选字段用 `?` · 枚举用**字符串联合**（不用 `enum`）。
- **只放类型与取数钩子**，**没有请求逻辑**。
- **漂移靠测试发现**：接口契约由浏览器层与拟人层对着真实后端验证（见 `14-testing.md`）。

## 4. 取数钩子

- **一处实现**：加载 · 错误 · 取消 · 重试只有一个实现，全站复用。
- **统一返回形状**：组件按同一套字段判断渲染，不各写一套 loading / error 分支。
- **不引数据缓存库**：axios · SWR · TanStack Query 都不用。

## 5. 流式

- **SSE 与 WebSocket 都经 `transport/`**，接线 · 鉴权 · 重连由它一处负责。
- **本层只描述消息形状**：事件类型与载荷类型写在类型里，不含连接管理。

## 6. 禁止

- 不许在组件里写 `fetch` / `EventSource` / `new WebSocket`。
- 不许在本层实现传输或鉴权（见 `15-platform.md` §4）。
- 不许引 axios / SWR / TanStack Query 等数据层库。
- 不许为旧服务端做兼容分支。

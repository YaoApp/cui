# architecture/ — 写给 Agent 的编辑规则

> 本目录的文档由 Agent 维护。这份文件说**怎么改**：写成什么样、什么不许写、改完跑什么。
> **给人读的导览与章节索引在 [`README.md`](README.md)** —— 那份只讲"有哪些册、各管什么"。

## 1. 写作规则

**读者是 Agent，只写会改变行为的东西。**

- **写规则，不写现状**：**app 代码会被重置**，所以「目前只有 X」「现在走的是 Y」迟早变假 ——
  只写"该怎么做""允许什么 / 禁止什么"。现状与进度放 `plan/`。
- **不写「待讨论」**：开放问题要么写成"该怎么做"，要么写成"不做 + 为什么"；未决事项放 `plan/`。
- **一条规则只在一处写全**，别处给编号引用；一个概念的所有分支写在同一册，别让读者去别处拼。
- **举例用通用名**（`inbox` · `chat` · `data-table`），不要写死真实脚手架里的页面或组件名。
- **理由只在推不出来时才写**；其余给指向具体文件的指针。
- **能表格就表格**，不写散文；标题与正文用规范用语（构成 · 落位 · 归属 · 约束 · 边界 · 关系），
  不用口语（"长什么样" · "放哪" · "要不要…"）。

## 2. 通用格式（`00-principles.md` 是样板，照抄，不许自创）

```
# <编号> · <名>
- **版本** / **最后修改** / **说明**

## 1. <本册的硬规则>      列表，一条一句
## 2. <主题>              章首一句话总纲；**定义**用类型 / 图 / 表给出
### 2.1 <分支>
## n. …                  编号即可引用；结论先行，细则往后
```

- **规范只写定义与规则**：类型 · 字段 · 允许值 · 禁止事项。**不写实现细节**（`undefined` · 初始值 ·
  某段代码怎么写），也不叙述现状。
- **名字由规范给**：类型名 · 字段名 · 概念名都在规范里写明，**代码照它实现**；
  实现里先起个名字、规范里没提，读者会把一件事当成两件。

## 3. 路径与引用

- **路径从包根写全**：一律以 `packages/celadon/` 为根（`app/src/…` · `design/…` · `scripts/…`；
  仓库根的文件写 `../../…`）。**别混用文档相对路径**（`../design/…`）——同一册里两套写法，读的人就得猜。
- **引代码入口，不引设计**：要指**代码在哪**（`app/src/…`）。`design/` 是**设计规范**，作用是"编码时看它"，
  不是代码依赖；只有讲"改设计 → 跑转换"的流程时才提它。
- **别引用 `plan/` 的内容**（那是过程文档，会删）：只提"目录本身"（如"进度放 `plan/`"）。
  **引用的路径要能长期存在。**
- **路径与命令必须真实存在** —— `check-doc-references.mjs` 会拦（见下）。

## 4. 改完必须过门禁

```bash
pnpm check        # 规范门禁：11 个检查器（含文档引用、文档结构、语言包、产物一致性）
pnpm lint         # 基础语法：stylelint · eslint · tsc
pnpm test:all     # 六层全链：lint → gates → checkers → unit → browser → build → persona
```

- **`check-doc-references.mjs`**：文档提到的 `app/src/...` 路径 · `scripts/*.mjs` · `pnpm <cmd>` 必须真实存在。
- **`check-plan-md.mjs`**：`plan/` 的表格结构；**单元格里别写竖线**（检查器不认转义）。
- **改完先核对，再提交**：不要用"整张清单回滚"这类钝器清改动戳 —— 它会连刚写的规则一起删掉
  （2026-10-02 因此丢过一整册的改动）。只回滚"除版本 / 最后修改外没有实质改动"的文件。

## 5. 与邻居的边界

- [`design/`](../design/) 管**长什么样**（视觉唯一来源）；**本目录**管**代码怎么摆**；
  [`plan/`](../plan/) 管**做到哪了**。
- **三者不重叠**：视觉规则不在本目录复述，计划状态不在本目录记录。
- **视觉规则只在 `design/` 定，工程规则只在本目录定。** 两边都不许在代码里出现"第三份真相"。

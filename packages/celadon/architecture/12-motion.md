## 1. 规则

- **默认 CSS + token**；入场 / 退场用 CSS 过渡：挂载首帧挂一个入场状态、下一帧摘掉，由过渡走完。不用关键帧动画，节点被重新插入时引擎会把动画从头再跑一遍；视图切换用 **View Transitions**。
- **只有手势 / 编排 / 布局动画用 `motion`**（`^13`）。
- **减动效**：CSS 一侧由 token 层统一把时长归零；用 `motion` 的一侧由库的 `useReducedMotion()` 读同一偏好并退化为瞬时，因为弹簧参数写不进自定义属性。
- **每个动效场景必须标注归属**（CSS / 原生 / `motion`）—— 不允许"顺手引个库"。

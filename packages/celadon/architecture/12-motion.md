- **状态**：✅ 已定

- **说明**：动效归属（规格见 design）

## 规则

- **默认 CSS + token**；入场 / 退场用 `@starting-style`；视图切换用 **View Transitions**。
- **只有手势 / 编排 / 布局动画用 `motion`**（`^13`）。
- **每个动效场景必须标注归属**（CSS / 原生 / `motion`）—— 不允许"顺手引个库"。
- 减动效由 token 层统一处理（系统"减少动态"→ 全部时长归零），**组件不需要各自判断**。

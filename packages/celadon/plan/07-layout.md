## 2. 三栏与窗口

- **列序**：互换只对调内容区与标签浏览器，导航列恒为第一，用显式 `order` 表达，不用 `row-reverse`。
- **让位顺序**：内容区先到最小 400，然后标签浏览器到最小 300，然后导航区收起为零宽，最后标签浏览器整条收成零宽。窄视口两档按视口宽度判定，与手动收起走同一个状态。
- **面板独占**：整栏占满整扇窗口，导航区与内容区让位，`Esc` 退出；独占与导航收起同时成立时按独占优先。
- **状态与偏好**：侧别 · 分屏方向 · 分屏比例 · 本栏宽度 · 两组标签都记本机并刷新保持；标签与面板的绑定是装配层的视图状态，不入偏好。

## 3. 导航列

- **四段结构**：头部内块（品牌 · 整列收起键 · 客户端窗口控制）· 上区主导航（六项，图标加文字）· 下区当前（场景名一行常驻，二级导航由插槽给）· 底部一行（头像与名字 · 两个快捷图标）。
- **收起态**：三端一律收成零宽，内容区从窗口最左铺满；重新展开的入口在内容列头左端，没有图标轨这一档。
- **上区折叠**：一级菜单可单独折起，折起后下区「当前」与展开键常驻；样式只认 `[data-width='zero']` 与 `[data-main='folded']` 两个状态属性。
- **宽度可调**：夹在 `--nav-min` 264 与 `--nav-max` 420 之间，初始 280；上限另受窗口宽减内容区最小 400 减第三栏最小 300 的约束，越界时样式与逻辑各夹一次。位移不到 4 像素按点击处理，方向键每次 8 像素，`Home` 与 `End` 到上下限，双击复位。
- **行状态**：悬停 `--nav-hover`，当前项 `--nav-select` 配 `--text-primary`（不用品牌色），一级与二级同一套；换底 120 毫秒、只过渡底色与文字色。未读数由装配层给，二级菜单的角标当前不渲染。

## 4. 内容区

- 列头三段：标题 · 两端的找回键 · 拖窗口顶带。找回键由装配层给描述子（图形 · 展开态 · 可不可见 · 是否置灰 · 文案 · 点击），列头不认识角色。
- 中栏底 `--background-surface`，与导航列、标签浏览器各差一档，靠底色分栏。

## 5. 标签浏览器

- **键与图标口径**：三处图标键统一 `Button` 的 `small` 加 `plain` 加图标 16，命中区 24 × 24；顶栏内距 8、栏高 `--row-height`。
- **顶栏**：前段标签与新建键，后段下拉、最大化或恢复、关闭；不加下边线，空白处仍是窗口拖动顶带，右键开同一个下拉菜单。菜单上段是溢出的标签，下段是换边与两项分屏。
- **标签模型**：一项记为 `{ key, target, title?, icon? }`，`key` 在页的生命周期里不变，装什么由 `target` 决定；关闭看这一页现在装什么，还是首页那一页时不可关。内容在本页里换，`key` 与位置不变，标签名与图形跟着变。
- **溢出**：条上不放的进 `⌄` 菜单上段，当前页一定留在条上（放不下时替掉可见段末尾那一项）；标签行始终渲染全部标签，放不下的收成 `data-hidden`，宽度照量得到；新建键在预算里被预留。
- **拖动换序**：位移不到 4 像素按点击，超过才进入拖动；落点画 2 像素插入指示线；拖动期间不做过渡、锁住文本选择，`Esc` 取消，松手提交并记本机。
- **截断标题**：统一 `Tooltip`，触发元素是覆盖整段标题的主体；被省略的那层取 `pointer-events: none`，避开 WebKit 对省略号元素自弹的原生提示。
- **关闭键**：命中区 24、图形 14，用 `visibility` 显隐，悬停放大 1.2 并提亮，不加底色。

## 6. 分屏

- **两组标签**：两栏各有一组标签与自己的活动页，互不引用；key 由同一个分配器给出，全仓唯一；两组各记一份持久化。
- **位置**：左右分屏新栏在左、主栏在右，两段标签条并排留在顶栏；上下分屏主栏在上、新栏在下，两块各自在顶部有一条标签条。
- **一条线**：整条栏位只有一条分隔线，从顶栏下缘贯穿到栏底，两栏宽度与顶栏左段共用同一份比例，拖动时也始终只有这一条。
- **关空与合并**：新栏的首页可关，关到一个不剩自动退回单栏（单关、关闭其它、关闭全部、批量关闭都走同一条订阅；刷新恢复时若分栏开着而新栏为空则补一张首页）；主动关分屏时新栏的页按顺序并入主栏并去重。
- **方向门槛**：左右看本栏实际宽度是否够两块并排（两倍 `--side-min` 加分隔条），上下看本栏页面实际高度是否够两块叠放（两倍 `--pane-min-height` 加新栏标签条），不够时置灰并写明原因，两个方向各判各的。
- **每栏自带操作**：新建、切换、关闭、拖动、`⌄` 溢出菜单与右键菜单都只作用于所在那一组；新栏的菜单项与本栏的 store 动作一一对应。

## 7. 无障碍

- 每组标签条有自己的 `idPrefix`（`browser-primary` / `browser-secondary`），标签带 `id` 与 `aria-controls`，被控面板带 `role="tabpanel"` 与跟着活动页走的 `aria-labelledby`。
- 两条 `tablist` 的名字分别是「主栏标签」与「新栏标签」，四语齐。
- 新建键在 `tablist` 之外，读屏不会把它念成标签。
- 分隔条是 `role="separator"`，带 `aria-label`、`aria-valuemin` 20、`aria-valuemax` 80 与当前比例的 `aria-valuenow`。

## 8. 动效

- **第三栏收放**：栏内是「裁切层加定尺内容壳」，栏宽变化只改开窗大小，内容按落点宽度排版一次、动画期间不重排；宽度与 `min-inline-size` 放同一条过渡，收起态把最小值压到零。
- **两处收放**：容器都是稳定盒子，互换只改顺序与位置、不重建节点；收放与分屏用 CSS 过渡（`--duration-base` 配进场减速缓动）。
- **减少动态**：`prefers-reduced-motion: reduce` 下不加过渡，收放瞬时到位；拖动分界线与分隔条期间一律不做过渡。

## 9. 关键读数

- 第三栏收放（真 Safari，1324 视口，逐帧）：展开 0 → 400 共 13 帧，除起步一帧 31 毫秒外帧间隔 14 到 19 毫秒；收起 400 → 0 同档。两个方向栏内文本宽度全程只有一个取值。
- 三栏让位：宽 1280 时 280 / 600 / 400；1000 时 280 / 400 / 330；969 时导航收起为 0；700 时第三栏整条为零宽。
- 换边后（导航 / 内容 / 标签浏览器）：1500 时 280 / 820 / 400；1280 时 280 / 600 / 400；969 时 0 / 569 / 400；706 时 0 / 0 / 706。最后两档收掉的是内容区，与「收掉次栏」的口径相符。
- 换边后收放内容区（内容 / 标签浏览器，真 WebKit 逐帧）：收起 820/400 → 497/723 → 276/944 → 141/1079 → 26/1195 → 0/1220；展开 0/1220 → 426/794 → 601/619 → 715/505 → 819/401 → 820/400。两个方向都走满 `--duration-base`。
- 标签条与两处菜单的五态（浅 / 暗，被绘制元素的计算值）：悬停底 `rgb(237, 237, 240)` / `rgb(44, 42, 38)`，当前底 `rgb(232, 232, 235)` / `rgb(51, 49, 41)`，菜单项悬停底 `rgb(240, 240, 242)` / `rgb(44, 42, 38)`，菜单项禁用文字 `rgb(168, 166, 158)` / `rgb(95, 90, 82)`，焦点环 `rgb(20, 18, 14)` / `rgb(244, 241, 234)`、宽 3。
- 分屏对齐（1600 视口，栏先拖到约 720）：顶栏左段 880..1232，新栏 880..1232，分隔线在 1236；拖动 80 像素后 880..1154 与 880..1152，差 2 像素（亚像素取整），仍只有一条线。顶栏两段的第一颗标签分别在 888 与 1244，留白一致；两栏「首页」底色都是 `rgb(232, 232, 235)`。
- 方向门槛：1600×900 两颗键都可用；1280×800 左右置灰（栏宽不足）、上下可用；1600×520 上下置灰（高度不足）。

## 11. 不做与以后

- **不做**：未读数的真实数据（只接 `badge` 口子）· 内容区的单区与两栏两种形态 · 外部地址页的真实抓取 · 关闭标签后其余标签的跟随位移（有意保留瞬时就位）· 分屏超过一层 · 标签历史跨会话同步 · 窄栏时按「标签条 → 下拉 → 最大化 → 收起」逐颗收键。
- **以后**：窄视口手动展开为浮层（由「窄视口且已展开」派生，沿用同一个收起开关；浮层脱离弹性流、宽度取存值、背后遮罩、不画把手，`Esc`、点遮罩、选中条目三条关闭路径）；只做 Web 端，客户端里导航收起是零宽、窗口可拉宽，不需要这一档。

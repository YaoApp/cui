# 03 · 组件

> **承接**：`00` 把 **F9 插画与空状态**移交到本模块（空状态本质是"一个组件的六种变体"）。
> 做组件时一并定：① 空态组件（无数据 / 无结果 / 无权限 / 出错 / 加载中 / 首次使用，各含文案位与主行动）
> ② 它引用的插画规格（风格 · 尺寸档 · 用色 · 与图标的边界）。若插画将来被多处独立复用再单独立项。

- **状态**：⏳ 待开始
- **目标**：2.0 的基础组件与状态规格（按钮/输入/徽标/气泡/卡片/空态/加载/错误）
- **范围**：组件清单与四态（default/hover/active/disabled）· 表单控件 · 消息与卡片 · 空态与骨架屏
- **不包含**：业务组件（各模块自带）
- **依赖**：00 设计规范 · 01 基础设施 · 02 布局
- **素材来源**：界面稿 `design/mock.html` 中的组件样式；旧包 `packages/cui/components` 按需复制
- **验收（Done）**：① 每个组件四态齐 + focus-ring 可见 ② 全部走语义 token，零硬编码 ③ 四语不截断（en 长 30%）

# 08 · 布局：内容区与标签浏览器的镜像（讨论）

- 状态：讨论稿（2026-10-16）。第 2 节的口径、第 5 节的原则与第 6 节的实施清单已定；第 7 节还有一条要定，定稿后写进 `design/main-shell.md` 与 [08-layout-implemented.md](08-layout-implemented.md)。
- 依据：`design/foundations.md` F6（三栏竖分割与让位）· `design/main-shell.md` §五（第三栏）与 §七（独占）· `routes/layout.less`（列序）· `components/content/parts/head/`（内容列头的键）· `components/browser/`（顶栏与标签条）。

## 1 现状：键位与行为

| 键 | 位置 | 何时可见 | 点击之后 |
| --- | --- | --- | --- |
| 导航列收放键 | 导航列自己的头部 | 常驻，指针进导航区才出现 | 收起导航列（收成 0 宽） |
| 导航找回键 | 内容列头左端 | 导航列收起时 | 展开导航列 |
| 标签浏览器收放键 | 本栏顶栏后段最右那颗 | 常驻 | 收起本栏，宽度过渡到 0，内容区让位 |
| 标签浏览器找回键 | 内容列头右端 | 本栏收起时 | 把本栏找回来 |
| 标签浏览器最大化或恢复 | 本栏顶栏后段 | 常驻 | 本栏独占窗口，再点恢复 |
| 下拉 | 本栏顶栏后段 | 常驻 | 开菜单：换边 · 左右分栏 · 上下分栏 |
| 新建标签 | 标签条末尾 | 常驻 | 在末尾开一个空页 |

两个把手的口径：导航列右缘与内容区、标签浏览器之间的分界线各一条，取 `--side-resize-handle`，悬停 300 毫秒才亮出高亮带，双击回到本栏默认宽。

## 2 一致性的口径（已定）

**键按角色定位，不按屏幕端点定位。** 三栏的角色与列序无关：

- **主栏**：中间那一栏，视觉中心；承载当前场景的主内容。
- **次栏**：主栏之外、离导航最远的那一栏；可以收掉的那一栏。
- 后两栏互换只换谁站在主栏、谁站在次栏，不换这套角色。

由此得五条：

1. **槽位不变。** 两种列序下用同一批槽位：主栏头部左右两端各一个，次栏头部一个，标签条末尾一个。收起态与展开态的两颗键**轮流用同一个槽位**，因此不存在同一端挤两颗键的情况，标题的预留空间与现在一致，不跳。
2. **位置的语义照旧。** 主栏头部左端那个槽位的语义就是今天内容列头左端那个槽位（导航找回键），主栏头部右端就是今天内容列头右端（次栏找回键）；镜像态里它们长在标签浏览器顶栏的前段与后段，取的是同一套左右关系。前段那颗键在标签条**之前**，标签条因此整体右移它的宽度。
3. **次栏的收放键留在次栏自己的头部、在自己的槽位上，且换边不让它消失。** 正常态次栏是标签浏览器，键在顶栏后段；镜像态次栏是内容区，键在内容列头的槽位上。它收不动时（主栏不在、次栏已是最后一栏）按既有 blocked 口径处理：禁用并给 blocked 提示，与分屏键在窄窗下同一档。主栏不画收放键。
4. **找回键按要找的那一栏在哪个方向决定端点。** 导航在左，导航找回键在主栏左端；次栏在右，次栏找回键在主栏右端；主栏不在时回落画在留下的那一栏的对应端点。
5. **镜像状态要记。** 键位的角色推导以它为输入，跨会话保留。

F6 的让位顺序按角色读同一句话：**次栏先让（内容区先压到最小）→ 主栏再让（标签浏览器压到最小）→ 导航区收起 → 次栏整条消失**。镜像态里次栏是内容区、主栏是标签浏览器，顺序不变，于是最后消失的是主栏，主内容活得最久。

这条只针对 web。Windows 与 macOS 的壳自带窗口按钮带，键位各按它们自己的口径，不在本册范围。

**状态与推导**

| 项目 | 取值 |
| --- | --- |
| 状态落点 | `stores/layout/columns.ts` 的 `browserSide: BrowserSide`（`'left' \| 'right'`） |
| 持久化 | 已在 `cui.layout` 里持久化（`partialize` 收了 `browserSide`），第 5 条不需要新增存储 |
| 主栏 | `browserSide === 'right'` 时是内容区，`'left'` 时是标签浏览器 |
| 次栏 | 主栏之外的那一栏 |
| 推导落点 | 装配层（`routes/layout.tsx`）一处算出两个槽位要装什么，内容列头与标签浏览器顶栏只按传进来的槽位渲染，不各写判断 |

**按这条口径推出的键位**

| 槽位 | 正常（内容在主栏、标签浏览器是次栏） | 镜像（标签浏览器在主栏、内容是次栏） |
| --- | --- | --- |
| 导航列头部 | 导航列收放键 | 同左 |
| 主栏头部左端 | 导航找回键（内容列头左端） | 导航找回键（标签浏览器顶栏前段，Home 之前；标签条右移其宽度） |
| 主栏头部右端 | 次栏找回键（内容列头右端） | 次栏找回键（标签浏览器顶栏后段右端） |
| 次栏头部 | 次栏收放键（标签浏览器顶栏后段最右） | 次栏收放键（内容列头的同一槽位，换边不消失） |
| 标签浏览器顶栏后段其余两颗 | 下拉 · 最大化或恢复 | 同左（收起键的槽位保留，两颗键位置不动） |
| 标签条末尾 | 新建键 | 同左 |

**两处由此定下来的结果**：标签浏览器顶栏的下拉与最大化在镜像态不消失（那时它是主栏，不会收起；只有正常态里它作为次栏被收起时才随本栏一起隐藏，这是现状）；镜像态内容列头不新增槽位，次栏收放键用的是该列头原有的槽位。

**槽位的占位口径**：槽位在任何状态下都占住宽度，收起态与展开态的键在同一个槽位里换内容，键的显隐不带动画、也不推动邻居（沿用内容列头现在「不展示用隐藏实现，占位保留，标题因此不跳」的做法）。镜像态前段那个槽位因此常驻，标签条的起点固定，不因导航列的收放而抖动。

**文案复用**：导航找回键用 `shell.navigation.action.expand`，次栏收放键用 `shell.browser.action.collapse`（镜像态它收的是内容列，文案本身只说「这一栏」）、不可用时用 `shell.browser.action.blocked`，都不新增键。

## 3 正常与镜像的对照

「正常」指内容区在主栏、标签浏览器是次栏；「镜像」指标签浏览器在主栏、内容是次栏。两者由列序切换（`data-browser`），只互换内容区与标签浏览器，导航列恒为第一。

| 项目 | 正常 | 镜像 | 差异 |
| --- | --- | --- | --- |
| 列序 | 导航列 · 内容区 · 标签浏览器 | 导航列 · 标签浏览器 · 内容区 | 互换只发生在后两栏 |
| 主栏 | 内容区 | 标签浏览器 | 找回键都画在主栏头部 |
| 次栏 | 标签浏览器 | 内容区 | 收放键画在次栏自己的槽位上 |
| 键位槽 | 见第 2 节表 | 同一批槽位 | 槽位不动，槽位里的键按角色换 |
| 标签条起点 | 顶栏左端 | 顶栏左端再让出导航找回键的槽位 | 镜像态标签条整体右移，槽位常驻 |
| 让位顺序 | 次栏先让 → 主栏再让 → 导航区收起 → 次栏整条消失 | 同一顺序（次栏此时是内容区） | 镜像后空间从另一侧让出，顺序不变 |
| 收起后的空间归属 | 次栏宽度交给主栏 | 同左 | 仍是宽度让渡，只是从另一侧长出来 |

## 4 收放与滑入的几种情形

宽度过渡用逻辑属性写（`inline-size` 与 `min-inline-size`），镜像后视觉方向自动反向，不需要为镜像另写一套。

| 情形 | 触发 | 谁在动 | 谁让位 | 正常下面向哪边 | 镜像下面向哪边 |
| --- | --- | --- | --- | --- | --- |
| 展开次栏 | 点次栏找回键或菜单里的动作 | 次栏宽度由 0 长到存值 | 主栏让出宽度 | 内容区向左让 | 标签浏览器向右让 |
| 收起次栏 | 点次栏收放键 | 次栏宽度收到 0 | 主栏得到宽度 | 内容区向右长 | 标签浏览器向左长 |
| 收起导航列 | 点导航列收放键 | 导航列宽度收到 0 | 紧邻导航的主栏得到宽度 | 内容区向左长 | 标签浏览器向左长 |
| 展开导航列 | 点导航找回键 | 导航列宽度长回存值 | 主栏让出宽度 | 内容区向右让 | 标签浏览器向右让 |
| 标签浏览器独占 | 点最大化或恢复 | 本栏铺满窗口 | 导航列与内容区让位 | 无方向 | 同左，退出后回到原列序 |
| 窄到放不下 | 窗口压到阈值 | 按 F6 顺序依次压 | 次栏先让、主栏最后消失 | 无方向 | 同一顺序，最后消失的是标签浏览器 |

## 5 实施原则：正常态是契约（已定）

正常态的键位、几何、Tab 序与文案是既有契约，镜像只加分支。实施时逐条守住：

1. **正常态逐个照旧**：角色推导的默认值就是现在的正常态；改完要跑一遍现有全部用例，正常态断言一条都不许改（只允许新增镜像态用例）。
2. **不动标签条本身的口径**：新建键紧跟最后一个标签且常显、放不下的进菜单、当前页一定留在条上、拖动 4 像素阈值、标签条不可选中，这些都不因为镜像而变。
3. **不动让位与宽度口径**：F6 的阈值、各栏最小最大宽、把手尺寸与悬停口径不动。
4. **不动动画口径**：时长与缓动取既有 token，镜像靠逻辑属性自动反向，不为镜像另写一套。
5. **同一条规则只在一处写**：键位的角色推导写在装配层一处，内容列头与标签浏览器顶栏都从它取；不各写一份判断。

**已知风险与防法**

| 风险 | 为什么会坏 | 防法 | 要同步的既有物 |
| --- | --- | --- | --- |
| 标签条前段多一颗键 | 它落在标签条行内，`use-tab-overflow` 现在只把新建键从预算里扣掉 | 前段那颗键与新建键同一处扣预算，槽位常驻 | `hooks/use-tab-overflow.ts` · `tests/overflow.browser.ts` |
| 拖动与点击误触 | 标签行接了指针事件，关闭键靠 `closest('.browser__tab-close')` 豁免；前段那颗键没有豁免会被当成拖动起手 | 前段那颗键加同样的豁免 | `hooks/use-tab-drag.ts` · `tests/drag.browser.ts` |
| 键盘 Tab 序 | 前段新增一颗会插在标签条之前 | 按下节清单更新 Tab 序并加用例 | `design/main-shell.md` §五 · `tests/keyboard.browser.ts` |
| 顶栏拖动带 | 顶栏空白处是窗口拖动区，前段那颗键必须不参与拖动 | 沿用键的 `cursor: default` 与拖动豁免口径 | `platform/client/window.ts` 的用例 |
| 窄窗主栏消失 | 让位把标签浏览器整条收掉时，主栏头部不在 | 两个找回键回落画在留下的那一栏的左右槽位；次栏收放键按第 7 节处理 | F6 与本册 |

## 6 实施清单

1. 装配层按「主栏 / 次栏」推导键位（见第 2 节的推导表），一处判断；镜像状态沿用 `stores/layout/columns.ts` 的 `browserSide`，已在 `cui.layout` 里持久化。
2. 两个头部改成按槽位渲染：内容列头与标签浏览器顶栏各接「导槽 / 尾槽」两个描述子（装什么键 · 是否显示 · 是否禁用 · 点击回调 · 无障碍名），不各自判断角色。
3. 标签浏览器顶栏前段新增导航找回键的槽位，槽位常驻，标签条整体右移其宽度；溢出预算里扣掉它；行内给它关闭键同样的拖动豁免；它不参与顶栏拖动。
4. 内容列头的槽位按角色装键：正常态左端导航找回、右端标签浏览器找回；镜像态右端装次栏（内容）收放键，左端留给导航找回（主栏不在时回落）。
5. Tab 序更新为：前段导航找回 → 标签条 → 新建 → 下拉 → 最大化或恢复 → 收起；写进 `design/main-shell.md` §五并加断言。
6. 镜像态用例的准备方式：走菜单里的「换到另一侧」（或直接把 `columns` store 的 `browserSide` 置为 `'left'`），每个用例开头显式设定，不依赖上一条用例的遗留。
7. 正常态回归：现有全部用例一条不改；另加镜像态用例，覆盖键位与槽位、标签条右移与槽位常驻、让位方向、Tab 序各一条。
8. 回写：`design/main-shell.md` §五的键位与 Tab 序两行、[08-layout-implemented.md](08-layout-implemented.md) 的对应条目；本册定稿后并入已实现册。

## 7 还需要定的一条

**窄窗让位把主栏（镜像态是标签浏览器）整条收掉时，内容列头同时需要三颗键**：左端导航找回（导航也已收起）、右端主栏找回（把标签浏览器找回来）、以及内容自己的收放键。内容列头只有两个槽位。三条路：

1. **找回优先，收放键此时不画**（槽位保留）：与内容列头现在「不展示用隐藏实现，占位保留」的做法一致，但违反了「收放键换边不消失」的字面。
2. **收放键禁用保留，三颗键同排**：字面一致，但内容列头要能容三颗键，标题可读宽度被再挤一次，需要重新量。
3. **收放键在这一档移进下拉菜单**：键位最省，但引入了「同一动作两个入口」的先例。

这一条定了之后，本册即可定稿并开工。

## 8 本轮不动的东西

- 导航列与标签浏览器的宽度取值、让位顺序与 F6 的阈值。
- 收放动画的时长与缓动（`--duration-base` 与 decelerate）。
- 分屏与独占的既有口径，除非第 6 节明确要动。
- Windows 与 macOS 壳的窗口按钮带。

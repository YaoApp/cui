## 3. 次要（11，摘要）

- 仍存在自造尺寸字面量（`16px` / `18px` / `176px` 等）散落在三页。
- 大量**抄来的死 CSS**：登录/注册页里留着只服务服务器页的规则；`</header>`、多余 `</script></script>` 之类的残留。
- 服务器页 `failed` / `empty` 两种状态**代码写了但不可达**（没有触发路径）。
- `<title>`、语言菜单、主题按钮 `aria-label` 仍有写死的英文。
- 三页没有任何 `@media`（窄屏只靠 `min(100%, …)` 兜底），也没有交互说明（焦点顺序 · 回车提交 · 错误定位 · 断点行为），与 `design/AGENTS.md` 的草图约定不符。
- 品牌渐变文字在浅色下最暗端 2.68:1、最亮端 1.92:1（低于正文 4.5:1）。
- 服务器页名称与登录/注册页的号位、行距在不同语言下未按 `--line-height-cjk` 分栈。

## 4. 建议（2）

- 把「控件边界」的取值固化成一处决策（默认档 / 达标档 / 低对比档各用在哪），避免每页各自选。
- 三页共用的外壳（横条 · 卡片 · 控件容器 · 语言菜单）抽成一份 `prototype/shell.css`，减少同源分叉。

## 5. 确认没问题的（11）

四语文案键齐 · token 用法基本规范（无字面量色值）· 浅暗两套截图成对 · Tab 顺序合理 · 按钮与复选框焦点环正确 · 图标符号齐全且品牌素材未改动 · 角标圆角与卡片一致 · 语言菜单层级在浮层之上 · 客户端内隐藏品牌与协议生效 · 独立页不受客户端模式影响 · 生成物（`tokens.css` · `i18n/bundle.js`）与源同步。

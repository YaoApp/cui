## 2. 头像

| 项 | 规则 |
| --- | --- |
| 底色 | `--brand` 实心；文字 `--brand-text`，实测 4.77:1，满足 AA |
| 首字母 | 名字首个字符转大写；中文名字取第一个汉字；空名回退 `U` |
| 图片 | 有图用图，`object-fit: cover`，圆形；加载失败回退首字母 |
| 尺寸 | 导航列 32 · 菜单身份段 32 · 资料页 64 |
| 团队层叠 | 账号属于团队时，在头像右下角叠一个 18 的团队徽标：底 `--background-surface`，文字 `--brand-ink`，外圈 2 像素 `--background-surface` 让两层分开；位置右下各出 2 像素。个人账号不叠 |

尺寸与层叠的取值（导航列 32 + 团队徽标 18，叠在右下）：

```
   ┌─────────┐
   │  ┌───┐  │
   │  │ M │  │   32 用户头像，底 --brand
   │  └───┘  │
   │      ┌─┐│
   │      │T││   18 团队徽标，2 像素描边
   └──────┴─┘┘
```

## 3. 底部一行

| 项 | 取值 | 说明 |
| --- | --- | --- |
| 行高 | 48 | 比条目行高一档，上方一条 1 像素 `--border-subtle` |
| 内距 | 左 12，右 0 | 右侧不留内距，让快捷图标与上方整列收起键对齐 |
| 触发区 | 头像 + 名字 | 这一块是按钮，`aria-haspopup="menu"` 与 `aria-expanded`；右侧两个快捷图标是独立链接，不放进按钮 |
| 名字 | 正文档，`--text-secondary` | 单行省略；悬停给全名 |
| 快捷图标 | 24 × 24 命中区，图标 16，间距 4 | 悬停底与图标同高，不与相邻图标连成一条；最右一格的右缘与 `.nav__toggle` 齐平 |

三种状态：

| 状态 | 表现 |
| --- | --- |
| 加载中 | 32 圆形骨架 + 一条 120 × 8 的名字骨架，不显示菜单箭头 |
| 已登录 | 头像、名字、套餐或团队名由资料给 |
| 未登录 | 灰色圆形头像（`--background-hover` 底、`--text-secondary` 的人形图标），名字位写「未登录」，点击直接去登录，不弹菜单 |
| 加载失败 | 名字位写「账户不可用」，头像回退首字母，菜单仍可打开，菜单里只有外链与「重试」 |

导航列收起为零宽时，这一行随列隐藏；入口改在内容列头的用户按钮，位置与「展开导航」同一组，菜单右对齐。

## 4. 菜单

### 4.1 分段与取值

| 段 | 行 | 高 | 左 | 右 | 动作 |
| --- | --- | --- | --- | --- | --- |
| 身份 | 头像 · 名字 · 套餐 | 56 | 32 头像 | 无 | 打开设置 · 个人资料 |
| 用量 | 用量与升级 | 32 | `i-obj-quota` | 剩余额度 | 打开设置 · 用量（升级见下） |
|  | 升级按钮 | 32 | 通栏反色 | 无 | 打开套餐页（外部） |
| 主操作 | 设置 | 32 | `i-nav-settings` | `⌘,` / `Ctrl+,` | 打开设置 |
|  | 团队 | 32 | `i-nav-team` | `i-right` | 打开设置 · 团队 |
| 链接 | 首页 | 32 | `i-home` | `i-act-external` | 浏览器新开一页，桌面壳交系统浏览器 |
|  | 帮助 | 32 | `i-nav-help` | `i-act-external` | 同上 |
|  | 文档 | 32 | `i-book` | `i-act-external` | 同上 |
| 退出 | 退出登录 | 32 | `i-nav-logout` | 无 | 常规配色，先弹确认 |

外观：宽 = 导航列实际宽度减 16（跟随拖动，不写死），内距 6，`--background-surface`，1 像素 `--border-subtle`，`--radius-medium`，`--shadow-floating`；段间三条分隔线，左右内缩 8。行内距左右 12，图标 16 与文字间距 8。

### 4.2 行为

- 打开：点击头像与名字块，或键盘 `Enter`／`Space`。
- 关闭：点击外部、`Esc`、选中一项。`Esc` 把焦点还给触发按钮。
- 键盘：打开时焦点进菜单第一项；上下方向键移动；`Home` 与 `End` 到首尾；`Tab` 关闭菜单并移到下一个可聚焦元素。
- 弹出方向：向上；空间不足时改为向下（视口小于 560 高时）。
- 滚动：菜单最大高度 `min(480px, 100vh - 96px)`，超出在菜单内滚动，触发区不动。
- 减少动态：弹出与收起只保留透明度，时长取 `--duration-fast`，减少动态时归零。
- 升级按钮：与用量行同宽，反色（`--brand` 底、`--brand-text` 字），不因套餐为 Team 而隐藏，文案随接口返回的套餐变化。
- 退出：`AlertDialog` 确认，标题「退出登录？」，说明一句，按钮「取消」与「退出登录」；确认后调用现有 `features/auth/sign-out`，回到登录页。
- 外链：Web 用 `target="_blank"` 新开；桌面壳调用桥的 `open` 交给系统默认浏览器（能力开关先判断）。
- 未登录：只画「未登录」身份段、三个外链与「登录」；用量、设置、团队、退出不画。

## 5. 架构与组件拆分

| 层 | 落位 | 职责 |
| --- | --- | --- |
| 基础件 | `app/src/components/base/avatar/` | 纯展示：图片或首字母、尺寸、团队徽标、加载骨架；不认识用户与团队的业务 |
| 组件 | `app/src/components/user-menu/` | 触发按钮、弹层、分段与行、键盘与焦点、确认弹窗；数据全由 props 给，不认识接口 |
| 组件 | `app/src/components/nav/parts/footer/` | 底部一行：接入 `Avatar` 与 `UserMenu` 的触发区；右侧两个快捷图标保持现状 |
| 装配 | `app/src/routes/layout.tsx` | 把账户、用量、动作（打开设置、打开链接、退出）交给 `Nav`，再由 `Nav` 传给 `Footer` |
| 业务 | `app/src/features/account/` | `use-account-menu.ts`：取资料与用量，组装 view-model 与动作；mock 开关也在这里判定 |
| 数据 | `app/src/data/user/` | 扩 `profile` 与 `usage` 的接口、查询键与类型；`mock.ts` 放 fixture |
| 文案 | `app/src/components/user-menu/locales/` | 四个语言包，键前缀 `userMenu.` |

`user-menu` 不放进 `nav`，因为导航列收起后同一份菜单要挂在内容列头的用户按钮上。

## 7. mock 设计

- 开关：`VITE_ACCOUNT_MOCK=1`，只在前端；生产构建不打开。
- 位置：`app/src/data/user/mock.ts`，导出 `mockProfile` 与 `mockUsage`；查询层在开关打开时返回 fixture，不经过 `transport/`。
- 数据形状：

```
profile: { user_id, name, nickname, email, avatar?, team?: { team_id, name, plan } }
usage:   { plan, remaining, unit, upgrade_url }
```

- 行为：延迟 200 毫秒；`VITE_ACCOUNT_MOCK_ERROR=1` 时返回 500，用来验加载失败与「账户不可用」。
- 边界：mock 只替换这两条查询；退出登录仍走真实流程（本机无会话时会直接回登录页）。

## 8. 验收

- 底部一行：24 见方命中区，两个图标的悬停底与图标同高，最右一格与整列收起键同一条竖线（`layout.shell.browser.ts` 有一条几何用例）。
- 头像：有图、无图、团队层叠三态都能看见；底色与文字色实测对比度不低于 4.5:1。
- 菜单：打开、`Esc`、点击外部、选中一项都能关闭；`Esc` 后焦点回到触发按钮。
- 未登录与加载失败两种状态可见，外链仍可用。
- 退出登录先弹确认，取消不退出，确认后回登录页。
- 四语切换后菜单文案全部跟着换，无硬编码。
- 窄窗口（520 × 600）下菜单不出界，面板内可滚动。

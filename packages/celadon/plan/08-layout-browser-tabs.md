## 6. 实现记录

- **面板独占与导航区收起同时成立时本栏右侧空一条**：根因是两条上限的层叠顺序。`layout.less` 里「导航区收起后把内容区那一份让出来」的 `.layout[data-width='zero'] .browser { max-inline-size: calc(100% - var(--center-min) - var(--side-resize-handle)) }` 写在独占那条之后，两者选择器权重相同，于是后者压过 `.layout[data-exclusive] > .browser { max-inline-size: none }`，本栏被限到 `100% − 408`，右侧空出一条；导航区展开时那条不成立，所以只在收起时出现。修法是在该规则之后补一条更高权重的 `.layout[data-exclusive][data-width='zero'] > .browser { max-inline-size: none }`。回归用例 `app/src/components/browser/tests/exclusive-width.browser.ts` 量本栏与面板的宽度等于视口宽（1200 ± 2）。
- **第 2 至 5 条第一版实现并回退**：改完顶栏结构后跑既有用例 15 条失败（分屏两键从顶栏收进菜单，用例点击路径全变），当时未迁移用例，工作区整体回退。
- **第 2、3、4、5 条与用例迁移同批落地**：新建键移进标签行且只有首页时不渲染；下拉键换 `i-down`、菜单改为换边与两项分栏；后段加最大化/恢复与关闭两颗键；顶栏空白右键开同一菜单。用例同批迁移：当时那个布局用例文件（后按层拆成 `layout.shell.browser.ts` · `layout.split.browser.ts` · `layout.exclusive.browser.ts` · `layout.motion.browser.ts`）里 18 处「按名字点分屏键」改为先开下拉再点菜单项（新增 `openTabMenu` 辅助），三处独占改点 `.browser__maximize`，一处「从菜单收掉这一栏」改点 `.browser__close`；`browser.test.tsx` 两条按新结构重写（分栏那条补 `width: 800` 让菜单项可用）。`e324af5c` · `ddf349aa`
- **第 6 条落地**：内容列头的找回键改成打开时整颗不画、收起后出现；零宽的槽不裁子元素，所以该槽在 `data-hidden` 时单独用 `display: none`。用例两条跟着改（收起改点 `.browser__close`，加「打开时不存在」的断言）。`5bc65176`
- **标签悬停时 ＋ 看起来被推一下（只在 Safari 复现）**：根因在绘制层，不在布局。关闭键原来用 `opacity: 0 → 1` 显隐并带过渡；WebKit 会给不透明度小于 1 的元素单独建层，指针一进一出就建层、撤层，整行跟着重栅格化，旁边的 `＋` 与右侧键的字形被重新栅格化，看起来像位移。`getBoundingClientRect()` 与静帧截图都量不到，因为布局没变。修法是把显隐换成 `visibility: hidden → visible`（不带过渡），只改绘制可见性、不建层。定位过程一并去掉了这一行里其它 WebKit 敏感写法：标签根节点不再用 `MotionPanel`（motion 布局投影会在元素上写 transform）、关闭键不套 `Tooltip` 与基础 `Button`、去掉 `:has()`、过渡只写 `background-color`、不再用 `margin-inline-start: auto`。规则：**标签的关闭键用 `visibility` 显隐，不用 `opacity`**。`3aa49439` · `81748b62` · `ec1d5663` · `8965a05b`
- **标签样式收口（纯图标关闭键 · 边距一致 · 宽度下限）**：关闭键去掉底色与圆角，成为纯图标，悬停改为放大 1.2 并把颜色由 `--text-secondary` 提到 `--text-primary`，命中区仍固定 24、图形 14；块的右内距改为 0，叉号到右缘的间距等于到上下的间距（各 5）。没有关闭键的页（首页）块取居中、左右内距各 8，实测左右留白相等（块宽 64，左右各 9.48）。宽度下限由 96 收到 48，短标题不再占一大片空底。缩放按 F4 的口径把图层在平时提升（`will-change: transform`），不在悬停瞬间建层。`9fc9345e` · `21bdf496`
- **拖动分界线时列内文字抖动**：`use-column-resize.ts` 的 `paint` 原样写入指针算出的宽度（小数），列内文字与图标每一帧重新吸附像素。修法是写入前取整（`Math.round`），与 `onCommit` 口径一致；列宽因此是整数，拖动与还原走同一条路径。`b3afb2b8`
- **只有首页时新建键不画、只有首页时标签居中**：新建键按 `tabs.length > 1` 决定是否渲染；没有关闭键的页由 `data-closable` 落在块上，样式按它切内距与居中，不用 `:has()`。`e324af5c` · `6f7e2377`
- **截断标题上出现两只提示气泡（只在 Safari 复现）**：根因是 WebKit 会给「正在被 `text-overflow: ellipsis` 截断的元素」自己弹一个原生提示，它与 `title` 属性无关，元素上写空 `title` 也压不住，所以查页面属性查不出来，Chromium 与合成事件下也复现不了。修法三条：① 被省略的标题层取 `pointer-events: none`，指针落不到它身上，原生提示没有可瞄准的对象；② 截断信息由统一 `Tooltip` 承担，触发元素取覆盖整段标题的主体（指针落在图标或留白上也弹），截断判定挂 `ResizeObserver` 在块上并在指针进来之前算好，否则第一次悬停赶不上当次指针事件；③ 判定留一像素余量（`scrollWidth - clientWidth > 1`），两个读数都是取整值，小数宽度上会出现一像素假差，短标题会误弹。标题另取 `flex: 0 0 auto`，标签行宽度不够时短标题不被挤成省略号。真 Safari 复验：短标题悬停无气泡，长标题悬停只有一只深色气泡。`0f30fdd4` · `c31ef6af` · `c71ae847` · `9bc2ee9f` · `e1060775` · `8e235e1d` · `d50d8678` · `55d94646`

# 08 · 标签浏览器分栏：实施计划

## 设计稿

分栏是**整条侧栏一分为二**：不只分页面，连标签条也按栏切开，每条标签条只装属于自己那一栏的页。
新栏（第二栏）总是后切出来的那一半；主栏保留原来的身份、原来的标签与原来的行为。

### 左右分栏

```
┌───────────────────────────────┬───────────────────────────────┐
│ [首页] [a.example] [＋] ⌄     │ [首页] [b.example] [＋] ⌄ ⛶ ⊟ │  ← 两条标签条各归各栏
├───────────────────────────────┼───────────────────────────────┤
│                               │                               │
│        新栏（第二栏）          │         主栏（原样）          │
│                               │                               │
│   新栏自己的页，自己切换       │    原来的标签条、原来的页      │
│                               │                               │
└───────────────────────────────┴───────────────────────────────┘
                                ↕ 分隔条：拖动改两栏比例
```

- 顶栏被竖直切成两段，左段是新栏的标签条，右段是主栏的标签条；两段用同一个比例变量算宽度，接缝与页面分隔条对齐。
- 溢出菜单每组各一个；分栏键与收起键只在主栏那一段。
- 分隔条从顶栏下缘起、贯穿两块页面，拖动它两栏同比例变化。
- 新栏在左、主栏在右。

### 上下分栏

```
┌───────────────────────────────────────────────────────────────┐
│ [首页] [b.example] [＋] ⌄                          ⛶ ⊟        │  ← 主栏的标签条
├───────────────────────────────────────────────────────────────┤
│                                                               │
│                      主栏（原样）                              │
│                                                               │
├───────────────────────────────────────────────────────────────┤ ↕ 分隔条
│ [首页] [a.example] [＋] ⌄                                     │  ← 新栏的标签条
├───────────────────────────────────────────────────────────────┤
│                                                               │
│                      新栏（第二栏）                            │
│                                                               │
└───────────────────────────────────────────────────────────────┘
```

- 整条侧栏被水平切成两块，上块主栏、下块新栏，两块都在块顶画自己的标签条。
- 主栏的标签条与三颗键保持原样；新栏只多一个自己的溢出菜单。

### 两栏的归属

| 项 | 主栏 | 新栏 |
| --- | --- | --- |
| 标签条 | 顶栏右段（原位置） | 左右分栏在顶栏左段；上下分栏在自己那一块的顶部 |
| 标签与活动页 | 原来那一组，不动 | 自己独立的一组 |
| 新建、点击、关闭、右键、拖动 | 只作用于本组 | 只作用于本组（不看焦点栏） |
| 溢出菜单 `⌄` | 有 | 有，各自独立 |
| 分栏键、收起键 | 只在主栏这一段 | 不重复放 |
| 外链打开（页面内提交的地址） | 焦点栏在主栏时落主栏，否则落新栏 | 同左 |
| 关到空 | 回落到首页 | 分栏自动关闭，回到单面板 |

## 1. 口径（实现依据）

1. 整条侧栏一分为二，标签条随栏切开，每条只装自己那一栏的页。
2. 两组独立，主栏 store 与既有用例不动，持久化只新增字段。
3. 左右分栏新栏在左、主栏在右；上下分栏新栏在下、主栏在上。
4. 比例统一为**新栏占比**；栏宽不加宽，低于 600 不允许左右分栏。
5. 标签条的一切操作只作用于本组；外链按焦点栏落点。
6. 新栏关到一个不剩（任何路径）时自动关闭分栏，回到单面板。
7. 跨栏拖动不做；新栏与主栏的 key 全局唯一。

## 2. 具体实现

### 2.1 状态层（步骤 1、2）

| 函数 | 作用 |
| --- | --- |
| `openIn` · `navigateIn` · `openBlankIn` | 开一页、页内换内容、放空白页 |
| `closeIn` · `closeOthersIn` · `closeAllIn` | 三种关闭；关空返回空组 |
| `activateIn` · `moveIn` | 激活（带存在性校验）、组内排序（「移除后再插入」口径） |
| `rememberIn` | 「打开过」，上限 8，两组各自一份 |
| `nextKey` | 全仓唯一 key，两组共用计数器；首页键按组区分 |

- `tabs.ts` 保留状态、动作名、`cui.browser` 持久化与 `migrate`，动作内部改调纯函数。
- `secondary.ts` 用同组纯函数，`persist` 键 `cui.browser.secondary` 版本 2；`seed()` 幂等、首页可关、`clear()` 清标签与活动页但保留「打开过」。
- `columns.ts` 的 `splitRatio` 注释改写为新栏占比；读取旧值时按 `1 - 旧值` 迁移，迁移写进 `cui.layout` 的版本升级里（不是就地改值）。

### 2.2 标签条与菜单（步骤 3、4）

- 新增 `parts/tab-menu/`：溢出菜单（放不下的页 + 操作项）与标签右键菜单（刷新、关闭其它、关闭全部、可关计数），两份都接「本组动作 + 本组计数」，主栏与新栏各渲染一次。
- `parts/tabs` 的属性补 `group`（`data-group`）、`idPrefix`、`menu` 插槽；`＋` 与 `⌄` 从标签行里移出，`useTabOverflow` 的预留从「一个新建键」改为「新建键 + 溢出键」。
- 顶栏结构：`主栏段`（新栏标签条 + 中缝 + 主栏标签条 + 主栏的 `⌄`/`⛶`/`⊟`）；长度用 `--split-ratio` 的 `flex-basis` 算，接缝与页面分隔条同一条线。镜像态的交通灯留白（`barInset`）给顶栏**第一段**，不是固定给主栏段。

### 2.3 新栏与排布（步骤 4、5）

- `parts/secondary-pane/`：接 `tabs`/`activeKey`/四个动作 + `menus`；`split === 'columns'` 只渲染页面，`split === 'rows'` 渲染「标签条 + 页面」。
- DOM 固定「主栏 · 分隔条 · 新栏」；左右分栏 `order: -2`（新栏）与 `order: -1`（分隔条），上下分栏不改序。切方向时**页面**不重挂（同一 key、同一容器），标签条会因换父节点重挂，这是接受的代价，写进文档。
- 比例：`--split-ratio` 同时喂两栏尺寸与顶栏两段；旧 `splitRatio` 迁移见 2.1；进分栏时重置 0.5 的行为保留，并在用例里断言。
- 分隔条与新栏之间的边框只留一处，避免与现有 `::before` 叠成双线；左右分栏时新栏左缘与整栏分界线的两个抓手要错开，不能重叠。

### 2.4 装配层（步骤 6、7）

- 新栏的页由第二组活动页渲染；页面内提交的地址按焦点栏落到对应组的 `navigate`；「打开过」也按组。
- 第二组清空（订阅 `tabs.length === 0`）→ `setBrowserSplit('none')` + 焦点回 0；主动关分栏 → 并入主栏并去重 → `clear()`。
- 旧模型字段处置：删 `layout.tsx` 的局部第二面板状态与 `browser.tsx` 的 `secondaryLabel`、`.browser__pane-head`；**保留** `browser.tsx` 的 `secondaryKey`（它是镜像态内容栏的找回键），不要与旧的第二面板字段混淆。
- 启动时若 `browserSplit !== 'none'` 而第二组为空 → `seed()`；若当前方向按新门槛放不下 → 收回为 `none` 并给一次可读提示。

### 2.5 判定、无障碍与文档（步骤 8、9、10）

- 两根判定（左右看宽、上下看高）都按实际尺寸；两颗键各自的 `disabled` 独立，已开分栏时另一个方向不满足就不允许切换；置灰原因区分「窗口太窄」与「窗口太矮」，前者用 `shell.browser.split.blocked`，后者用 `shell.browser.split.tooShallow`，四语齐。
- 新增 `--pane-min-height` token 后必须跑 `node scripts/build-css.mjs` 并提交两份 `tokens.css`，否则 `check-generated` 会红；新 `.less` 要过 `check-css-vars` 与 `check-tokens`。
- 文档同步六处：`design/main-shell.md`（标签按栏各成一套、分栏两栏归属）、`design/foundations.md`（分屏的两个方向门槛与 `--pane-min-height`）、`plan/08-layout-implemented.md`（分栏一节重写）、`plan/README.md`（索引状态）、`architecture/07-routing.md` 与 `architecture/15-platform.md`（若涉及侧栏描述）。前四处已同步。

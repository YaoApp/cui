# 08 · 标签浏览器分栏：实施计划

## 设计稿

分栏是**整条侧栏一分为二**：不只分页面，连标签条也按栏切开，每条标签条只装属于自己那一栏的页。
新栏（第二栏）总是后切出来的那一半；主栏保留原来的身份、原来的标签与原来的行为。

### 左右分栏

```
┌───────────────────────────────┬───────────────────────────────┐
│ [首页] [a.example] [＋]       │ [首页] [b.example] [＋]  ⌄ ⛶ ⊟│  ← 两条标签条各归各栏
├───────────────────────────────┼───────────────────────────────┤
│                               │                               │
│        新栏（第二栏）          │         主栏（原样）          │
│                               │                               │
│   新栏自己的页，自己切换       │    原来的标签条、原来的页      │
│                               │                               │
└───────────────────────────────┴───────────────────────────────┘
                                ↕ 分隔条：拖动改两栏比例
```

- 顶栏被竖直切成两段，左段是新栏的标签条，右段是主栏的标签条；主栏那段的右端仍是下拉、分栏与收起三颗键。
- 分隔条从顶栏下缘起、贯穿两块页面，拖动它两栏同比例变化。
- 新栏在左、主栏在右：新栏是「切出来的那一半」，主栏的位置与观感保持不变。

### 上下分栏

```
┌───────────────────────────────────────────────────────────────┐
│ [首页] [b.example] [＋]                            ⌄ ⛶ ⊟      │  ← 主栏的标签条
├───────────────────────────────────────────────────────────────┤
│                                                               │
│                      主栏（原样）                              │
│                                                               │
├───────────────────────────────────────────────────────────────┤ ↕ 分隔条
│ [首页] [a.example] [＋]                                       │  ← 新栏的标签条
├───────────────────────────────────────────────────────────────┤
│                                                               │
│                      新栏（第二栏）                            │
│                                                               │
└───────────────────────────────────────────────────────────────┘
```

- 整条侧栏被水平切成两块，上块是主栏（标签条在块顶），下块是新栏（标签条也在块顶）。
- 新栏在下、主栏在上：与左右分栏同一口径，新栏是后切出来的那一半，主栏原样。

### 两栏的归属

| 项 | 主栏 | 新栏 |
| --- | --- | --- |
| 标签条 | 顶栏右段（原位置） | 左右分栏在顶栏左段；上下分栏在自己那一块的顶部 |
| 标签与活动页 | 原来那一组，不动 | 自己独立的一组 |
| 新建标签 | 主栏标签条右端的新建键 | 新栏标签条右端的新建键 |
| 下拉、分栏、收起键 | 只在主栏这一段 | 不重复放 |
| 焦点栏 | 指针落在哪一栏就归哪一栏 | 同左 |
| 关到空 | 回落到首页 | 分栏自动关闭，回到单面板 |

## 1. 口径（实现依据）

1. 整条侧栏一分为二，标签条随栏切开，每条标签条只装自己那一栏的页。
2. 两组独立：新栏与主栏各有一组标签，主栏的 store 与用例不动，持久化只新增字段。
3. 左右分栏新栏在左、主栏在右；上下分栏新栏在下、主栏在上。
4. 栏宽不加宽：左右分栏要求存值宽 ≥ 600，两栏从存值宽度里平分；上下分栏按栏高判定。
5. 下拉、分栏、收起三颗键只在主栏那一段；新栏不重复放。
6. 新栏关到一个不剩时自动关闭分栏，回到单面板，不出现空面板。
7. 分栏键不换位置，仍在顶栏右端；跨栏拖动不做，标签只在本栏内排序。

## 2. 具体实现

### 2.1 状态层（步骤 1、2）

- 新增 `stores/browser/tab-group.ts`：与实例无关的纯函数，输入输出都是「一组标签加活动页」。

  | 函数 | 作用 |
  | --- | --- |
  | `openIn(group, entry)` | 追加并激活一页，key 由传入的分配器给 |
  | `navigateIn(group, key, target, meta)` | 把某一页换成新目标；同目标已在别页则关掉本页并激活那一页 |
  | `openBlankIn(group, key)` | 在某一页上放空白页 |
  | `closeIn(group, key)` | 关闭一页；关空返回空组 |
  | `closeOthersIn` · `closeAllIn` | 关闭其它、关闭全部 |
  | `activateIn` · `moveIn` | 激活；组内排序（「移除后再插入」的索引口径写进注释与用例） |
  | `homeIn` · `rememberIn` · `nextKey` | 首页回落、最近打开上限、key 分配 |

- `tabs.ts` 改成薄封装：状态、动作名、`cui.browser` 持久化与 `migrate` 保留，对外接口与引用稳定性不变。
- 新增 `stores/browser/secondary.ts`：结构照 `tabs.ts`，独立持久化键 `cui.browser.secondary`（版本 1），有自己的「打开过」；`seed()` 在开分栏时放首页，`clear()` 在合并后清空。

### 2.2 标签条（步骤 4）

- 顶栏的标签条已是 `parts/tabs` 组件（标签项、新建、溢出、右键菜单、拖动排序、键盘），新栏直接复用。
- 左右分栏：顶栏里新的分组排在主栏之前（`.browser__bar-secondary`，中缝一条竖分隔线），各算各的溢出。
- 上下分栏：新栏那一块顶部画同一条标签条，主栏的顶栏不动。判定按 `split` 的方向给，两种方向都不新开一条全局标签条。

### 2.3 第二栏与排布（步骤 3、5）

- `components/browser/parts/secondary-pane/`：`split === 'columns'` 时只渲染页面；`split === 'rows'` 时渲染「标签条 + 页面」。组件接本组的 `tabs` · `activeKey` 与四个动作。
- `.browser__body` 的 DOM 次序固定为「主栏 · 分隔条 · 新栏」，视觉次序由 `order` 给：左右分栏新栏 `order: -1` 且分隔条也 `order: -1`（否则分隔条留在最右、压住本栏的分界线）；上下分栏新栏排最后。
- 比例统一为**新栏占比**，`use-split-resize` 加方向参数（左右分栏拖动方向取反），旧比例迁移时按「旧值即主栏占比」换算。
- 样式：新栏的标签条行、与分隔条相接一侧的分隔线、两种方向的排布；`[data-split] .browser__shell` 的 `var(--side-width-tool)` 兜底删掉前先确认没有别的使用者。

### 2.4 装配层（步骤 6、7）

- `routes/layout.tsx`：新栏的页由第二组 store 的活动页渲染；新栏内的地址入口走该组 `navigate`，不新开页、不落到主栏。
- 焦点栏决定新建标签与外链落在哪一组；第二组关空、合并、切方向、收起与换边之后焦点重置为 0。
- 关空即关分栏：第二组 `close` 后为空则 `setBrowserSplit('none')`，不向主栏搬标签、不改主栏活动页；刷新恢复时若分栏开着而第二组为空，补首页。
- 主动关分栏：第二组标签经主栏打开入口并入（key 冲突由主栏分配器重建），新栏活动页成为主栏活动页，然后 `clear()`。

### 2.5 判定与无障碍（步骤 8、9）

- `tooNarrowToSplit` 拆成左右与上下两条：左右看实际栏宽（≥ 600 + 8 像素分隔条），上下看栏高（面板最小高度新增 token）；装配层现有的 `splitBlocked`（视口宽 ≤ 1287）只挡左右。
- 两颗键各按自己的判定置灰，原因区分「窗口太窄」与「窗口太矮」，四语齐，接上已有的 `shell.browser.split.blocked`。
- 两组标签条各自 `tablist`，`aria-controls`、标签 id、新建键 id 按组生成（`data-group` 加 `idPrefix`）；新栏那一组加「新栏」限定。

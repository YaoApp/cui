# 08 · 布局：内容区与标签浏览器

- 上层：[08-layout-index.md](08-layout-index.md)（三栏骨架 · 导航列 · 外壳）
- 依据：`design/main-shell.md` §四（内容形态）· §五（第三栏：浏览器式的侧栏）· §六（入口与呈现方式）· §七（独占与运行）· `design/foundations.md` F6（三栏竖分割与让位顺序）· `architecture/12-motion.md`（动效的引入条件）
- 状态：进行中（2026-10-13）。分两轮：第一轮做列与窗口这一层的交互（互换 · 让位 · 分屏 · 独占 · 动效），第二轮做标签浏览器的其余细节（键盘 · 首页记录 · 状态齐）。

三栏骨架与两处收起已经落地（见 [08-layout-base.md](08-layout-base.md)、[08-layout-nav.md](08-layout-nav.md)），本册不重做骨架。本册管两件事：内容区与标签浏览器这两栏在窗口左右互换，以及标签浏览器自身补齐到设计里的样子。内容区不改形态，只把与相邻一栏有关的呈现（描边 · 列头留白）跟着位置走。

## 2. 先写回设计

下面这几条是这一轮新定的设计，代码之前先落进规范，之后照规范做。规范里写全，计划里只记落点。

| 要写的规则 | 落点 |
| --- | --- |
| 内容区与标签浏览器两栏互换，导航列位置与状态不变；互换后两侧各自保留原宽，分界线移位 | `design/main-shell.md` §三 与 §五 |
| 窗口压窄的让位顺序改为：内容区先压到最小，再压标签浏览器，最后收导航列（与现行 F6 相反） | `design/foundations.md` F6 · `design/main-shell.md` §三 |
| 标签浏览器的一层分屏：左右与上下两种方向、面板绑标签、分隔条可拖、栏宽不足时左右分栏禁用 | `design/main-shell.md` §五 |
| 面板独占窗口：聚焦面板占满整扇窗口，与系统的窗口最大化分开 | `design/main-shell.md` §五 与 §七 |
| 标签条右端最多两颗键加「…」菜单；只有首页时不画新建键；新建落在聚焦面板的首页 | `design/main-shell.md` §五 |
| 这几处动效都用 Motion，时长与缓动取现有 token，不用 `display: none` 切换，尊重减少动态效果 | `architecture/12-motion.md` · `design/foundations.md` 动效一节 |

### 3.2 算做完的样子

- 三栏几何：互换前 · 互换后 · 浏览器收掉三种状态下各留一份三栏 `x` 与宽的读数，导航列的前后读数一致。
- 让位：从 1280 压到最小的过程中每一步留读数，能看到 §3.1 第 4 条的三段。
- 分屏：单面板 · 左右 · 上下 · 独占四种几何各留一份读数与浅暗两张截图。
- 动效：五个动作各录一次，核对时长与缓动取的是 token；打开减少动态效果后再录一次，为即时。
- 四语与状态：新增文案四语齐；默认 · 悬停 · 焦点 · 禁用 · 独占中 · 空都有据可查。
- 门禁：`pnpm lint` · `pnpm check` · `pnpm test` · `pnpm build` 全过；本轮专项浏览器用例全过。

### 3.3 提交拆分

按处拆，一处一条：① 列序与分界线；② 让位顺序；③ 分屏结构与分屏键；④ 分隔条；⑤ 面板独占；⑥ 标签规则；⑦ 动效；⑧ 偏好；⑨ 文档回写（§2 那几条）。前七条各自跑该处的 Less 编译、`pnpm lint` 与相关用例后立刻提交。

## 5. 不做

- 内容区的单区与两栏两种形态（`design/main-shell.md` §四 的另外两种）。
- 外部地址页的真实抓取与渲染，维持占位。
- 标签浏览器宽度可调（本轮只做分屏两侧的比例）。
- 分屏超过一层（面板里再分）。
- 标签历史跨会话同步。

## 6. 风险与依赖

- 动效要在布局阶段搭好结构：三栏与两个面板必须是稳定、可测量的盒子，互换只改顺序与位置、不重建节点，否则 Motion 的布局动画量不到前后状态；这一条在第 1 条与第 11 条一起验。
- 让位顺序改了 F6，属于设计变更：先改规范再改代码，避免代码与规范各说一套。
- Windows 客户端的窗口起不来（进程活、窗口句柄 0），两部分交互的屏幕验证目前只能在 macOS 与 Web 上做；这一条与本册无关，但会挡住「两端各走一遍」的最后一拍。

## 0. 待办清单

### 0.1 标签浏览器内部

- [ ] **键盘与鼠标**：标签条 roving tabindex（只当前标签可 Tab 到）· 左右箭头切换 · `Enter` 与 `Space` 激活 · `Delete` 关闭当前标签（中键关闭已成）。Tab 序为 标签条 → 新建 → 下拉 → 最大化或恢复 → 关闭。指针位移不超过 4 像素算点击，超过算拖动，两者互不误触。落地后标签自身的焦点态随之可量，第 0.1 节里两条与之相关的缺项同时收口。
- [ ] **标签右键菜单**：刷新 · 关闭标签 · 分隔线 · 关闭其他标签 · 关闭全部标签；后两项按可用性置灰。「刷新」先接上回调（外部页目前是占位，回调暂无可见变化）。关闭当前标签后的激活规则为「右邻优先，没有右邻取左邻，都没有则落回首页」，现行 `stores/browser/tabs.ts` 的 `close` 已是这一条。
- [x] **溢出进菜单**：标签条不换行也不横向滚动，从前往后能放下的留在条上，其余进顶栏 `⌄` 菜单上段（图标加标题、点选激活、当前项标出当前态），两段之间只留分隔线。做法：标签行始终渲染全部标签，放不下的由 `data-hidden` 收成不可见并脱离排布、宽度照量；新建键在预算里被预留；当前页放不进可见段时替掉可见段末尾那一项，一个都放不下时只留当前页。`2a0bbdf8` · `55321663`，专题见 [08-layout-browser-tabs.md](08-layout-browser-tabs.md) 第 3 节。
- [x] **拖动换序**：标签横向拖动，落点决定次序并画一条插入指示线；位移不到 4 像素按点击处理，拖动期间不做过渡，`Esc` 取消，松手提交并记本机。store 的 `move` 按移除该项之后的数组算索引；指针捕获推迟到越过阈值之后，避免把随后的 click 重定向到整块而使点标签失效。`7fff4b9c` · `55321663`，专题见 [08-layout-browser-tabs.md](08-layout-browser-tabs.md) 第 4 节；键盘替代 `Alt` 加左右箭头随「键盘与鼠标」一条落地。
- [ ] **首页的「打开过的东西」**：按使用顺序记录打开过的页，同一份内容复用同一页；空态四语齐；有单元用例与一条浏览器用例。
- [ ] **地址的错误态**：空输入与非法地址有错误态，四语齐。
- [ ] **标签关闭后其余标签的跟随位移**：现为瞬时。原按布局投影实现，投影会在 WebKit 上引起重栅格化，已从标签上移除；改用哪种做法待定。
- [ ] **状态齐与截图**：默认 · 悬停 · 焦点 · 禁用 · 空逐条落实，浅色与暗色各一张截图。缺焦点态的那一处随键盘那条落地。

### 0.3 待定的设计与窄栏

- [ ] **窄栏与镜像**：窄栏优先级 标签条 → 下拉 → 最大化或恢复 → 关闭；镜像细节（键组贴哪一侧、找回键是否随栏换边）等结论后落。
- [ ] **窄视口手动展开为浮层**：规则是 F6 的「导航栏不参与宽度让步，视口窄时手动展开覆盖中栏，不挤压它」。实现形状：不新增状态机，窄视口下这一档由「窄视口且已展开」派生，沿用同一个收起开关；呈现仍是同一套展开态内容，只多一层浮层外壳（脱离弹性流、宽度取存值、背后一层遮罩、浮层内不画拖拽把手）；关闭三条路为 `Esc`、点遮罩、选中条目。安排在桌面客户端适配之后单独一批，客户端收起为零宽，浮层语义与 Web 不同，两档分开验收。窄视口下二级导航暂时不可达。
- [ ] **待清的技术债**：内容区与标签浏览器两处的内部资料指针注释、hook 归位（认证域的六个 `use-*.ts` 与脚手架的 `use-routing-url-sync.ts` 收进各自 `hooks/`）、token 检查器不校验 `var(--x)` 是否存在。

## 3. 风险与依赖

- 让位顺序改过 F6 的两条既有规则（顺序与导航列豁免），规范与代码当前一致。
- 分屏可能需要新 token（最小栏高 · 分隔条尺寸）；新增 token 走 `design/tokens.less` 与生成物，并与改同一份文件的其它实例错开。
- 溢出入菜单与拖动换序都会动标签条的结构，两条要一起排期：先按尺寸观测算出可见与溢出两段，再在标签上加拖动。
- 实时服务的浏览器用例在满并发下会抖（集中在登录与注册的实时服务路径），重跑前先单跑确认；浏览器基线按「单跑为准、满并发看趋势」记。

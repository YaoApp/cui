### 2.2 P1 · 结构与适配

- ✅ **F6 三栏竖分割（窗口与栅格）** —— 结论：**主结构是三栏竖分割**（导航区 | 内容区 | 侧栏，grid 列轨），**不是 web 断点表、也不是横向条带**；屏幕兼容靠**比例默认 + 视口驱动**，不靠"给不同屏幕不同窗口尺寸"。
  · **栏契约**：顶栏 `48`（按自身密度实测，非 web 式 64）· 导航 `264–420`（默认 `280`，收起 `56`）· 中栏最小 `400` · 侧栏 `≥300`、**默认宽按视图类型**（阅读 `400` / 工具 `600` / 任务 `640` / 宽屏 `840`）、绝对上限 `1280` 且 ≤`0.7×画面`；窗口默认 `1280×820`，最小 `520×600`
  · **让位顺序**：① 侧栏先缩（夹取）→ ② 侧栏整条消失（剩余不足 300 就**不开**，不压窄）→ ③ **中栏才可能低于最小**；**导航不参与宽度让步**（视口 <1024 自动收 56px 图标轨，手动展开则**覆盖**中栏，不挤压）
  · **屏幕兼容**：阈值按**视口 CSS px**（含系统缩放，4K@200% ≈ 1920 与 1080p 同构）；侧栏用**画面比例**；窗口记住上次尺寸；高度不足先收次级工具条、**底栏保留**
  产物：`tokens.less`（栏契约 + 比例）· `foundations.html` 栏契约表 + 屏幕兼容说明 + **三栏 grid 演示**（视口滑杆 / 导航宽滑杆 / 侧栏比例滑杆 / 两个开关，求解器 `computeColumns()`（最小宽预算 + 夹取，图形界面同介质验证过））
  自检（实测列轨）：默认 1280 → `280 | 1000 | 0`（两栏）· 开侧栏 2200 → `280 | 930 | 990`（侧栏=45%画面）· 1600 → `280 | 600 | 720` · 1280 → `280 | 424 | 576` · 1000 → `56 | 494 | 450`（<1024 自动收轨）· 手动展开 → 导航 `overlay` 且列轨保持 `56 | 439 | 405`（覆盖不挤压）✓

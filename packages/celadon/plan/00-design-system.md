### 2.2 P1 · 结构与适配

- ✅ **F6 三栏竖分割（窗口与栅格）** —— 结论：**主结构是三栏竖分割**（导航区 | 内容区 | 侧栏，grid 列轨），**不是 web 断点表、也不是横向条带**；屏幕兼容靠**按空间推导 + 视口驱动**，不靠"给不同屏幕不同窗口尺寸"。
  · **栏契约**：导航 `264–420`（默认 `280`）· 中栏最小 `400` · 侧栏 `≥300`、**默认宽按视图类型**（阅读 `400` / 工具 `600` / 任务 `640` / 宽屏 `840`）、**可拖拽调整**（把手 `--side-resize-handle` `6`），**上限 = 总宽 −（导航区 + 内容区最小 + 把手）**，**不写死比例或绝对值**；**没有标题栏** —— 唯一悬浮的是窗口左上角的「红绿灯 + 收起键」，**位置永不变**。
  · **让位顺序**：① 侧栏先缩（在最小与"剩余空间上限"之间夹取）→ ② 侧栏整条消失（上限不足 300 就**不开**，不压窄）→ ③ **中栏才可能低于最小**；**导航不参与宽度让步**。
  · **导航收起三档**：**客户端 = 收到 0**（导航区完全消失，内容从窗口最左铺满；内容顶行让出 `--titlebar-inset` `96`，红绿灯与收起键仍浮在原位）· **Web = 保留 56 图标轨**（`--nav-rail-icon 24` + `--nav-rail-pad 16`×2；hover 出标签、当前项指示条、aria-expanded）· 中档（<1024）= 自动收轨 · **Web 窄屏（<768）= 抽屉**（浮层 + 遮罩，Esc / 点遮罩关闭；入口在图标轨顶部或内容顶行汉堡）。**Web 没有红绿灯** → 不出现角部控件组。
  · **屏幕兼容**：阈值按**视口 CSS px**（含系统缩放，4K@200% ≈ 1920 与 1080p 同构）；窗口记住上次尺寸；高度不足先收次级工具条、**底栏保留**。
  产物：`tokens.less`（栏契约 + 标题栏/把手 token）· `foundations.html` 栏契约表 + 屏幕兼容说明 + **三栏 grid 演示**（视口滑杆 / 导航宽滑杆 / 侧栏开关 / **拖拽把手** / 平台与视图类型切换，求解器 `computeColumns()` 按最小宽预算夹取）
  自检（实测列轨）：默认 1280 开侧栏 → `280 | 600 | 400`（阅读型默认）· 向左拖到上限 → `280 | 406 | 594`（= 1280 − 280 − 400 − 6，公式命中）· 向右拖到底 → `280 | 700 | 300`（最小 300）· 侧栏关 → `280 | 1000 | 0`

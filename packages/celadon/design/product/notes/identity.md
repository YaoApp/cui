# 身份与构建

> 状态：草案 · 2026-10-23

`Memory` 模态窗按使用场景分三档。本文描述前两档的身份与构建内容，记忆本身见 [`memory.md`](memory.md)。

## 1. 面板结构

| 场景 | 第一档 | 第二档 | 第三档 |
| --- | --- | --- | --- |
| Session | 看板 | 会话 | 记忆 |
| Bots 会话 | 智能体 | 会话 | 记忆 |

入口位于 Session 与 Bots 会话头部，顺序为分享、Memory、Workspace。点击打开居中模态窗，关闭后回到原会话，不改变 Browser 当前页。

## 2. 看板构建

Session 的第一档显示会话所属的看板与列：

- 看板与列在新建会话时确定，面板内只读；
- 说明会话会成为该看板中的一张任务卡；
- 列表示工作域，不表示运行状态；
- 看板记忆作为后续能力，显示为计划项，与单会话记忆分开。

## 3. 智能体构建

Bots 会话的第一档显示 Bot 身份：

- 头像；
- 名称与英文名；
- 描述与能力标签；
- Workspace；
- 身份来源为 Bots 定义，会话内只读；
- 可以打开 Bots 定义，调整身份、技能与策略。

头像使用 Ghost 身体形态，尺寸按位置区分：导航与消息署名 24，首页卡片与头部 32，欢迎区 64，Memory 身份档 56。头像背景透明，容器决定落位。完整规则见 [`bots.md`](bots.md)。

## 4. 会话构建

第二档显示本次会话的执行条件：

- 标题；
- Workspace 与 Computer；
- 主智能体；
- 模型与思考强度；
- 看板与列，仅 Session 场景显示；
- 开始时间。

这些内容说明会话在哪里运行、由谁执行。修改运行参数从下一轮生效，不重建当前会话。

## 5. 交互

- 点击头部 `Memory` 打开；
- `Esc`、关闭按钮或点击遮罩关闭；
- 三档用 Tab 切换，默认打开记忆；
- 记忆开关与日志操作留在第三档，不混入身份与构建。

# Memory

> 状态：草案 · 2026-10-23

Session 详情与 Bots 会话头部提供 `Memory` 入口，打开居中的记忆与身份模态窗。本文只描述第三档的记忆管理；看板、智能体与会话构建见 [`identity.md`](identity.md)。

## 1. 范围

- 会话记忆只属于当前 Session，不跨会话共享；
- 记忆按 Session 独立存储，读取时不需要用户手动复制；
- 后续增加看板记忆，同一看板下的会话共享，与会话记忆分库；
- 当前版本不把看板记忆与会话记忆混合写入。

记忆只影响后续轮次的上下文，不改变会话的 Workspace、模型或运行状态。

## 2. 开关

记忆默认开启。

- 开启时，每轮结束后写入当天日志；
- 关闭后，已有日志保留，后续轮次不再写入新记忆；
- 重新开启后从下一轮继续写入，不补写关闭期间的内容。

## 3. 按天日志

- 日志按日期分组；
- 每天显示条数与当天摘要；
- 默认展开今天，其他日期按需展开；
- 一条日志只记一个主题，标题短语能独立读懂；
- 日志用于回看过程，摘要用于进入后续上下文。

## 4. 压缩摘要

- 滚动摘要保存当前目标、已确认约束与最近完成的工作；
- 接近容量上限时，把旧内容压缩为摘要，并把细节归档到对应日期；
- 面板显示当前摘要容量、上次压缩时间与压缩动作；
- 压缩后摘要继续进入后续轮次的上下文；
- 压缩不删除当天日志，只把已结束的内容从滚动摘要移出。

## 5. 文件

记忆由三类文件组成：

| 文件 | 作用 | 建议上限 |
| --- | --- | --- |
| `MEMORY.md` | 当前工作记忆与摘要索引 | 8 KB |
| `INSTRUCTION.md` | 用户明确要求长期遵守的指令 | 4 KB |
| `PREFERENCE.md` | 用户偏好 | 4 KB |

- `MEMORY.md` 只保留当前有效的事实、决策与进度；
- `INSTRUCTION.md` 只在用户明确要求长期遵守时写入；
- `PREFERENCE.md` 记录用户明确表达的偏好；
- 细节日志按日期归档，不放进滚动摘要；
- 三类文件都自动进入后续轮次的上下文。

## 6. 读取与追溯

- 当前会话的 `MEMORY.md` 自动进入上下文，不需要用户手动读取；
- 历史日志按日期浏览；
- 用户提到之前聊过的内容时，先查历史日志，再回答；
- 跨日期检索只用于找回上下文，不把整段历史直接塞进上下文。

## 7. 安全与边界

- 不把密钥、凭据或 API Key 写入记忆；
- 记忆内容不跨用户共享；
- 看板记忆上线前，不把会话记忆暴露给同看板的其他会话；
- 记忆开关与日志内容不改变 Bot 的身份、技能或权限。

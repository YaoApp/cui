# Apps

> 状态：草案 · 2026-10-23

App 是独立应用。它可以独立运行，有自己的数据、鉴权、页面与交互，不依附于平台 Chatbox。平台负责入口、资源绑定、分享与运行承载，不规定 App 内部版式。

App 与 Bot 的边界见 [`service.md`](service.md)。App 可以有 Agent 面，但 App 的人面由 App 自己定义。

## 1. 列表

Apps 列表是造与用的同一个入口。

| 字段 | 内容 |
| --- | --- |
| 身份 | 图标、名称、英文名 |
| 来源 | 自建或外部；外部再标记官方提供或第三方提供 |
| 描述 | 这个应用解决什么问题 |
| 分类 | Design、Commerce、Education 等 |
| 界面形态 | Canvas、Gallery、Print 等，帮助用户预期打开后的界面 |
| 资源 | 绑定的 Workspace |
| 状态 | Ready、Draft；运行状态不进入列表卡片 |
| 时间 | 最近更新时间 |
| 入口 | Open，点击进入独占详情 |

列表顶部按来源分成三个 tab：全部应用、自建、外部应用。外部应用下再分全部外部、官方提供、第三方提供。分类与搜索放在 tab 下方，作为第二层筛选。

列表还包含一张「做一个自己的应用」卡片。它与顶部「新建应用」使用同一个模态窗：输入应用需求，提交后直接进入新建 Session 的详情。搜索、分类与来源筛选只作用于已有 App，不改变 App 数据。

## 2. 独占详情

App 从列表或导航打开时进入独占页。

- 整扇窗口变成 App 自己的界面；
- 客户端导航、列表与 Chatbox 不出现；
- 外层只保留右上角胶囊：最小化与关闭；
- 关闭只关闭界面，不结束应用任务；
- 最小化回到 Apps 列表，并在右下角留下重新打开的入口；
- 应用顶行右侧要为胶囊留出位置。

独占页内部可以有应用自己的顶栏、左侧对话、画布、属性栏、底部工具栏或打印预览。平台不要求不同 App 使用同一套内部布局。

## 3. 分享

每个 App 顶栏提供分享入口。分享的是应用入口，不共享 Builder 的 Workspace、Vault 或运行数据。

分享窗包含：

- 可见范围：Team 或 Anyone with link；
- 入口链接；
- 复制链接；
- 只读入口说明。

## 4. 当前三个 App

### 4.1 海报设计 Poster Studio

- 左侧设计助手对话；
- 右侧海报画布与属性栏；
- 顶栏显示品牌、画布上下文、分享与导出；
- 属性栏显示尺寸、版式、品牌色与方向变体。

### 4.2 电商配图 Product Shots

- 左侧商品图助手对话；
- 右侧输出图库与选中图的规格栏；
- 图库按主图、场景图、卖点图、组合图组织；
- 规格栏显示输出平台、背景、卖点标注与生成记录。

### 4.3 教具制作 Teaching Aids

- 左侧教具助手对话；
- 右侧 A4 教具纸面预览；
- 教具、活动、打印三个视图；
- 打印设置独立成栏，显示纸张、卡片数量、裁切线与打印说明。

三个 App 共用对话输入、附件、语音与分享能力，但不共用主界面布局。应用内部页面与交互由应用自己决定。

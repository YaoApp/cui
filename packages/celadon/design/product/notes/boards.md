# 看板 Boards

看板是会话的容器。Kanban 是默认视图，列表示工作域，任务卡片对应一次会话。列的划分不表示运行状态，运行状态由任务自身的 `run_status` 表示。

## 1. 页面结构

- 一级导航的「看板」进入 `/boards`；
- 左侧是看板二级导航，列出全部看板、英文名与任务数；
- 内容区是当前看板，顶部为看板标题与任务数，下面依次是状态筛选、搜索与新建任务；
- 看板列横向排列，列内纵向排列任务卡片；列宽固定，超出内容宽度时横向滚动；
- 点击任务卡片从右侧打开任务详情，详情覆盖在看板上方，关闭后回到原位置。

## 2. 看板列表

二级导航显示：

- 看板图标与名称；
- 英文名；
- 任务总数；
- 当前看板选中态；
- 列表底部的「新建看板」，打开看板创建表单。

示例看板：

| 看板 | 说明 | 列 |
| --- | --- | --- |
| 业务工作台 | 市场、数据、内容与客户的日常任务 | 市场调研 · 数据报告 · 内容运营 · 客户洞察 |
| 产品迭代 | 从需求评审到发布的交付流程 | 需求评审 · 设计开发 · 测试验收 · 已上线 |
| 客户成功 | 客户对接、方案交付与培训支持 | 客户对接 · 方案交付 · 培训支持 |

## 3. 顶部工具栏

- 看板图标、名称、英文名、任务数与更新时间；
- 状态筛选：全部、待开始、运行中、等待中、已完成、失败，并显示各自数量；
- 搜索：任务标题、描述、Workspace、Bot 与标签；
- 新建任务：打开任务创建表单，选择标题、描述与所属列。

## 4. 任务卡片

卡片展示任务的关键信息，不展开完整会话：

- 状态图标与标题，置顶任务带「置顶」标记；
- 一行或两行描述；
- 运行中的当前步骤、等待中的问题、失败原因；
- 运行中任务的进度条；
- 标签，最多显示两个；
- 状态、下次运行时间与更新时间；
- Workspace 与 Bot 名称。

每列底部固定显示「新建任务」，点击后打开任务创建表单，并自动选中该列。列表为空时仍保留这个入口。

状态使用统一图标与颜色角色：

| 状态 | 显示 |
| --- | --- |
| 待开始 | 待开始 |
| 运行中 | 进度、当前步骤 |
| 等待输入 | 需要用户回复的问题 |
| 已完成 | 完成标记 |
| 失败 | 失败原因 |

## 5. 任务详情

任务详情由四个分区组成：

### 5.1 会话

- 显示用户与 Bot 的最近消息、附件与时间；
- 底部复用共享 ChatComposer，可以继续这个任务；
- 不显示「打开会话」一类跳转入口，任务本身就是会话。

### 5.2 信息

- 描述；
- 状态、分组、Workspace、Bot；
- 运行次数、定时、下次运行与更新时间；
- 标签。

### 5.3 文件

- 输入文件与产出文件；
- 显示文件名、类型图标与大小；
- 没有文件时显示空状态。

### 5.4 运行

- 状态、定时、下次运行与运行次数；
- 服务列表：名称、端口与运行状态；
- 没有服务时显示空状态。

## 6. 状态与边界

- 任务卡片只显示摘要，完整对话在详情里；
- 筛选与搜索只影响当前看板，不改变任务数据；
- 新建任务默认进入待开始，创建后立即打开详情；
- 新建看板默认包含待办、进行中、已完成三列，创建后自动切换过去；
- 看板只承载任务与会话，不展开分支树、浏览器或完整运行日志；
- 列是工作域，不把运行状态写进列名；
- 没有匹配任务时看板区域显示空状态。

# prototype/ — 产品草图（纯 HTML + 设计 token）

**用途**：先把 UE 与 UI 定下来，再写产品代码。草图只用于评审与沟通，**不进产品包**。

## 约定

1. 只引 [`../tokens.css`](../tokens.css)（取样例文案可再引 [`../i18n/bundle.js`](../i18n/)）；不引产品样式与应用代码。
2. 不出现字面量色值与自造尺寸（不写 `style="color:#…"`）。
3. 一页一文件，文件名即页面名：`login.html` · `register.html` · `servers.html` …
4. 每种页面覆盖**完整状态**，不只画成功路径：
   - 登录：空闲 · 提交中 · 用户名不存在（引导注册）· 密码错误 · 需要验证码 · 需要 MFA。
   - 注册：空闲 · 验证码已发（含重发倒计时）· 验证码错误 · 密码强度不足 · 两次输入不一致 · 需要邀请码 · 成功。
   - 服务器选择：无历史 · 有列表且当前可达 · 当前不可达 · 校验中 · 校验失败。
5. 文件内用注释写明交互说明（焦点顺序 · 回车提交 · 错误定位 · 禁用与加载态 · 断点行为）。
6. 浅色与暗色都要成立（切换 `.celadon` 作用域或 `data-theme`）。

## 怎么看

```bash
node packages/celadon/design/serve.mjs        # 默认 8080 → /prototype/login.html
```

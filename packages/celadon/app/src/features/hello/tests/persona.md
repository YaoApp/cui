## S4 的根因（不是颜色值错）

app 区域内每一处颜色都来自 token 且可读（标题 `rgb(244,241,234)` = `--text-primary` 暗档 ·
卡片 `rgb(22,41,42)` = `--brand-soft` 暗档 · 按钮亮青描边可辨）。缺的是**页面底色这一层**：

- `html` / `body` 没有任何背景 → 浏览器默认白；
- `.hello` 的 `min-block-size: 100%` 没有父高度可解 → 只覆盖内容高度；
- 另外 `body` 的默认 8px 外边距也还在（截图里那条带的左右各留了一点）。

按分层，这属于 **`app/src/platform/`（运行时壳）** 的职责 —— 而它还没建。

## 修了什么

按分层，页面底色与整页高度是 **运行时壳（`app/src/platform/`）** 的职责，而它此前根本不存在。新增 `platform/shell.less`：

```
html, body { block-size: 100% }
body { margin: 0; background: var(--background-app); color: var(--text-primary); font-family: var(--font-family-ui) }
#app { min-block-size: 100% }
```

`main.tsx` 引入它；顺带修掉 `body` 默认 8px 外边距（截图里那条带左右各留了一点）。

**回归用例**：`hello.spec.ts` 新增一条 —— 切深色后 `body` 的计算背景必须与浅色不同、且不是白、不是透明。
**先证明它会红**：把 shell 的 import 摘掉 → 该用例失败于 `Expected: not "rgba(0, 0, 0, 0)"`；装回去 → 通过。

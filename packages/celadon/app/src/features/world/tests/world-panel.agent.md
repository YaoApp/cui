| | |

## 剧本

### 场景

同事发给我一个地址，说"看这个门"。我想知道：**这个地址打开是不是就停在那个门上**，
**我自己点开一个门、地址会不会变成能发给别人的样子**，**按后退是不是就收起来了**，
**刷新会不会丢**，以及**我在旁边打字过滤时，开着的那扇门会不会被弄丢**。

### 怎么做

**S1 打开别人发的地址** —— 我打开 `/main/world/w1?sideEntity=e2`。

**S2 我自己点开一个** —— 我到 `/main/world/w1`，点「守门人」。

**S3 我按后退** —— 按浏览器后退。

**S4 我刷新** —— 我按刷新。

**S5 我顺手过滤** —— 我在「过滤」框里打 `alpha`。

### 判定数据（冻结）

**每张截图三件并用**：① 执行者视觉（布局 · 观感）② OCR（文字与参数**逐字精确**）③ 决策模型（分级 + 置信度）。

| 步 | 通过 | 不通过 | 看不清（不许并进"通过"）|
| --- | --- | --- | --- |
| S1 | 面板开着、写着「守门人」与编号 `e2`，**地址仍是带参的那个**（读进来不回写）| 面板不出现，或地址被改写 | 面板被遮或糊到读不出 |
| S2 | 面板出现，且地址变成含 `sideEntity=e2`（能复制给别人）| 面板不出现，或地址里没有该参数 | 地址栏被遮挡 |
| S3 | 面板收起，地址里不再有面板参数 | 面板还开着，或参数还在 | 面板与收起态分不清 |
| S4 | 刷新后面板仍在 | 刷新后没了 | — |
| S5 | 地址里**同时**有 `q=alpha` 与 `sideEntity=e2`，面板仍在 | 打字把面板参数挤掉，或把面板关掉 | — |

**转人**：需要口味与价值裁定时转人；证据不足且补不到时转人；低风险且有明确判据时执行者自己判。

### 不做的部分（写清为什么）

| 项 | 为什么不做 |
| --- | --- |
| 分享链接的**内容**是否正确 | 那是 `buildShareUrl` 的单测职责（`platform/utils/share-url.test.ts`）|
| 侧边表面（`/side/...`）的布局 | `deep-link.browser.ts` 已覆盖；拟人只验用户看得见的结果 |
| 面板样式是否符合设计 | 设计一致性由 token 与检查器把关，拟人不管观感打分 |

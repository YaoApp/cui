## 决策依据

- **品牌色相谱系**：调研（Pantone 2026 Cloud Dancer 柔白 · Claude `#d97757` 陶土橙 · Manus 暖黑 `#34322D` · Codex `#1C64C8`/`#63A8F8` · 中国传统色 384 色表）后定为 **`#2D8282`**：
  它落在「青」带（180°）——中文里唯一"既是蓝又是绿"的颜色词（青瓷 / 青花 / 青绿山水），饱和度 49%（不刺眼），且**白底文字正好过 AA**。
- **中性色**：近白/近黑（内容区非纯白，去刺眼）；浅暗同品牌值（用户定）。

## 红线（落地必守）

1. **单一来源**：颜色只改本文件；AntD 主题从同一份 token 生成；
2. **禁硬编码**：`less/tsx` 里不得出现颜色字面量（红绿灯 / 系统色除外）；
3. **暗色只覆盖 semantic**，component 层不重复写死；
4. **品牌色只出现在 3 处**：主按钮 · 选中态 · 徽标（其余中性）；
5. **暗色文字档**用 `--brand-lift`（`#2D8282` 在近黑上仅 4.19:1）；
6. **success 只用软底 + 图标**（`#057748` 与品牌青同绿系，避免混淆）；
7. `--r-pill` 仅用于徽标 / 标签 / 头像。

## 用法

```less
.btn-primary { background: var(--brand-soft); color: var(--brand); border: 1px solid var(--brand);
  &.is-solid { background: var(--brand); color: var(--brand-text); } }
.badge-warn { background: var(--warm-soft); color: var(--warm-text); border: 1px solid var(--warm); }
```
